Installare Legal IT

Legal IT è un plugin per Claude Code: 228 strumenti di diritto italiano (testo vigente da Normattiva ed EUR-Lex, Cassazione, Corte costituzionale, TAR e Consiglio di Stato, CGUE, calcoli di interessi, termini e parcelle), 30 procedure guidate, 9 comandi e 6 agenti specializzati. Funziona sul tuo computer. Servono circa dieci minuti.

Hai già Legal IT 2.x? Non serve reinstallare: vai a Aggiornare dalla versione 2.

Cosa ti serve

  • Claude Code: nel terminale oppure nella scheda Code dell'app Claude. Il passo 3 lo installa se non l'hai.
  • Una connessione a internet: il primo avvio scarica Python e i componenti necessari.
  • Python non serve. Lo installa da solo il programma del passo 1.

I passi

Scegli il tuo computer: le istruzioni cambiano.

  1. Installa uv

    uv scarica Python e le versioni esatte dei componenti di Legal IT. Si installa una volta sola.

    Apri il Terminale (⌘ Spazio, scrivi Terminale, Invio), incolla e premi Invio:

    curl -LsSf https://astral.sh/uv/install.sh | sh

    Apri PowerShell (tasto Windows, scrivi PowerShell, Invio), incolla con il tasto destro e premi Invio:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    Chiudi la finestra, aprine una nuova e controlla:

    uv --version

  2. Installa git

    Serve per scaricare il plugin dal suo archivio.

    xcode-select --install

    Si apre una finestra: premi Installa. Se dice che è già installato, sei a posto.

    Scarica e installa Git for Windows lasciando le opzioni predefinite. Claude Code su Windows lo usa anche per i suoi comandi.

  3. Installa Claude Code (se non c'è)

    Controlla con claude --version. Se il comando non esiste:

    curl -fsSL https://claude.ai/install.sh | bash
    irm https://claude.ai/install.ps1 | iex

    Chiudi e riapri la finestra, poi accedi con il tuo account Claude digitando claude una prima volta.

  4. Installa il plugin

    Nel Terminale (o PowerShell), un comando alla volta:

    claude plugin marketplace add capazme/mcp-legal-it
    claude plugin install legal-it@mcp-legal-it

    Il plugin vale sia per Claude Code nel terminale sia per la scheda Code dell'app Claude: si installa una volta sola.

    Se avevi installato l'estensione .mcpb in Claude Desktop, toglila (Impostazioni → Estensioni → Legal IT → Disinstalla): altrimenti nella scheda Code gli strumenti compaiono due volte.

  5. Primo avvio

    Apri Claude Code (digita claude in una cartella di lavoro, oppure apri la scheda Code dell'app). La prima volta Legal IT scarica Python, si collega, e poi scarica in background i suoi componenti: da qualche secondo a un paio di minuti, secondo la rete. Gli strumenti compaiono da soli quando il download finisce; se li chiedi prima, Claude ti dirà che Legal IT si sta preparando.

    Digita /mcp: legal-it deve risultare connected. Dal secondo avvio parte in meno di un secondo.

  6. Attiva gli aggiornamenti automatici

    Digita /plugin, apri la scheda Marketplaces, scegli mcp-legal-it e poi Enable auto-update. Senza questo passo le nuove versioni non arrivano da sole.

Prova

  • Calcola gli interessi legali su 10.000 euro dal 1° gennaio 2024 al 1° gennaio 2025.
  • /legal-it:norma articolo 2043 del codice civile
  • Cerca le sentenze recenti della Cassazione sul danno da perdita di chance.

La prima volta che usa uno strumento, Claude chiede il permesso: scegli l'opzione che non lo richiede più per quella sessione o per sempre.

Aggiornare dalla versione 2

Se hai attivato gli aggiornamenti automatici (passo 6), la versione 3.0 arriva da sola: chiudi e riapri Claude Code. Altrimenti, nel Terminale (o PowerShell), un comando alla volta:

claude plugin marketplace update mcp-legal-it
claude plugin update legal-it@mcp-legal-it

Poi chiudi e riapri Claude Code. Il primo avvio della 3.0 scarica di nuovo i componenti, come alla prima installazione; dal secondo avvio parte in meno di un secondo. Per controllare la versione chiedi a Claude: «Che versione di Legal IT sto usando?» (risponde lo strumento stato_server).

Cosa cambia per te:

  • Gli strumenti sono gli stessi, con gli stessi nomi. Alcune risposte che erano sbagliate senza avvisare ora sono corrette, oppure lo strumento si rifiuta e spiega perché (per esempio un intervallo come «art. 3-5 c.c.»: va chiesto un articolo alla volta).
  • Il controllo delle citazioni è più rigoroso e verifica anche le sentenze. Se ferma una risposta, Claude legge la fonte con lo strumento indicato e poi risponde.
  • Chi usava l'estensione .mcpb in Claude Desktop: scarica il nuovo file dalla pagina delle release e installalo con un doppio clic, come la prima volta. Sostituisce la versione precedente.

L'elenco completo delle novità è nelle note di rilascio.

Usare Legal IT senza Brocardi

Brocardi.it è l'unica fonte privata di Legal IT: note di dottrina e massime, mai il testo delle norme. Se preferisci non usarla, avvia Claude Code così:

LEGAL_BROCARDI=off claude
$env:LEGAL_BROCARDI="off"; claude

Se usi la scheda Code dell'app Claude, che non parte dal Terminale, aggiungi la riga "LEGAL_BROCARDI": "off" nel blocco "env" del file settings.json della cartella .claude nella tua cartella utente, poi riapri l'app. Per controllare, chiedi a Claude: «Brocardi è attivo in Legal IT?» (risponde lo strumento stato_server).

Nessuna richiesta parte più verso Brocardi.it e due strumenti (cerca_brocardi, fetch_law_annotations) spariscono; gli altri funzionano e dicono che Brocardi è disattivato.
